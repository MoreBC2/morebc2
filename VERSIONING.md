# MoreBC2 Versioning

MoreBC2 uses documentation releases to mark meaningful improvements in the knowledge base.

These are not BitcoinII software releases.

## Version format

Use:

```text
vMAJOR.MINOR.PATCH
```

## Version meaning

### MAJOR

A major version marks a stable public documentation milestone.

Examples:

- Public website launched.
- Core docs complete.
- Exchange integration package reaches verified status.
- Major restructuring of the documentation system.

### MINOR

A minor version marks a meaningful documentation expansion.

Examples:

- Wallet guide added.
- Node guide added.
- Mining guide added.
- RPC guide added.
- Explorer index added.
- Verification index expanded.

### PATCH

A patch version marks corrections and small improvements.

Examples:

- Fixed broken links.
- Corrected wording.
- Added missing source references.
- Updated review dates.

## Rule

Never use MoreBC2 versioning to imply BitcoinII protocol or software versioning.

MoreBC2 versions describe documentation status only.
