# MoreBC2 Documentation Taxonomy

**Status:** Framework

This taxonomy defines where content belongs.

When in doubt, choose the category that best describes the evidence level and purpose of the page.

## Users

For people trying to use BitcoinII.

Suggested locations:

- `docs/wallets/`
- `docs/mining/`
- `docs/nodes/`
- `docs/documentation/`

Topics:

- Wallet installation
- Sending and receiving
- Backups
- Sync troubleshooting
- Mining basics
- Running a node
- Frequently asked questions

## Developers

For people building with or around BitcoinII.

Suggested locations:

- `docs/developers/`
- `docs/documentation/`
- `docs/exchange/`

Topics:

- RPC usage
- Build instructions
- Configuration examples
- Network specifications
- Consensus overview
- Source-code references

## Infrastructure providers

For exchanges, explorers, pools, wallets, payment processors, and service operators.

Suggested locations:

- `docs/exchange/`
- `docs/developers/`
- `docs/nodes/`

Topics:

- Exchange integration
- Deposit/withdrawal monitoring
- RPC examples
- Release verification
- Node operation
- Explorer APIs
- Pool integration notes

## Researchers

For technical comparisons, background explanations, and non-implemented ideas.

Suggested location:

- `docs/research/`

Topics:

- Difficulty adjustment comparisons
- Mining algorithm explainers
- BasicSwap-style research
- Wallet architecture comparisons
- Security and cryptography background

Rule:

Research is not documentation.

## Community discussion

For proposals, opinions, ideas, and debates.

Suggested location:

- `docs/discussion/`

Topics:

- RFCs
- Open proposals
- Community ideas
- Unresolved questions
- Ecosystem planning

Rule:

Discussion is not implementation.

## History

For preserving past events and context.

Suggested location:

- `docs/history/`

Topics:

- Timeline
- Historical releases
- Past exchanges
- Older documentation
- Community milestones

Rule:

Historical information should not be treated as current unless re-verified.

## News

For dated factual updates.

Suggested location:

- `docs/news/`

Topics:

- New releases
- New explorers
- New guides
- New exchange listings
- Major repository changes

Rule:

News should say what happened, not what someone thinks it means for price or future value.

## Project maintenance

For MoreBC2 itself.

Suggested locations:

- Repository root
- `.github/`
- `templates/`

Topics:

- Governance
- Contributing
- Style guide
- Evidence scale
- Source registry
- Templates
- Roadmap
