# News

**Category:** News
**Status:** Draft
**Last reviewed:** 2026-06-30

## Summary

This section is for factual BitcoinII (BC2) ecosystem updates.

News pages should focus on what happened, when it happened, and where it can be verified.

News is not opinion. Commentary should live in Discussion or a clearly labeled community blog area.

## Good news entries

- New wallet release.
- New exchange listing.
- New explorer.
- New mining pool.
- Important repository update.
- Major documentation update.
- Confirmed ecosystem status change.

## Planned pages

- Release announcements index.
- Ecosystem update log.
- Repository update log.
- Documentation update log.
- Historical news archive.

## Rules

- Date every news item.
- Cite or link the source of the update.
- Avoid price hype and market predictions.
- Do not present rumors as news.
- If a claim is not confirmed, send it to Verification or Discussion instead.
- If a service is listed as newly active, include direct check date and evidence.
- If a news item later becomes outdated, link to a newer item or archive note.
