# Research

This section is for technical explainers, comparisons, and ecosystem analysis.

Research pages may discuss ideas that are relevant to BitcoinII (BC2), but they must not imply that something is implemented unless it is verified.

## Example use cases

- Explaining a technology that community members are discussing.
- Comparing different difficulty adjustment algorithms.
- Researching exchange listing requirements.
- Studying BasicSwap-style integration paths.
- Summarizing technical questions that need developer confirmation.

## Important rule

Research is not documentation.

For example, if community members discuss Dark Gravity Wave, a research page may explain what Dark Gravity Wave is, but it must clearly state that BitcoinII does not currently implement it unless that changes and is verified by source code or official releases.
