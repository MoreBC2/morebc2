## What to check

For each pool, verify:

- Site loads.
- BC2 is listed.
- Pool appears synced.
- Recent activity is visible, if the pool displays it.
- Fee model is documented.
- Payout threshold is documented.
- Connection information is documented.
- Last checked date is recorded.
