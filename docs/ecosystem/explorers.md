## What to check

For each explorer, verify:

- Site loads.
- Chain appears synced.
- Current block height is plausible.
- Blocks can be viewed.
- Transactions can be viewed.
- Addresses can be viewed, if supported.
- Public API exists, if claimed.
- Last checked date is recorded.
