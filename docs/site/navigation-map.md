## Navigation rule

If a page has not been reviewed, the navigation label should not imply final authority.

Examples:

- Use `Wallet guide` instead of `Official wallet guide`.
- Use `Explorer resources` instead of `Official explorers` unless verified.
- Use `Known unknowns` openly rather than hiding missing work.
