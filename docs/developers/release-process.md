# Release process guide

**Category:** Documentation
**Status:** Draft
**Last reviewed:** 2026-06-29

## Summary

This page will document the public BitcoinII Core release process as it can be verified from public sources.

It does not claim to know internal maintainer procedures.

## What is known from current review

The public GitHub release page currently shows observed releases including:

- `v0.27.0` — Genesis Release.
- `v0.27.1` — Update DNS seeds and chain transaction data.

MoreBC2 has not yet confirmed the complete release verification model.

## Release information to document

This page should eventually answer:

- Where are official releases published?
- Which assets are published for each platform?
- Are checksums provided?
- Are checksum files signed?
- Are release tags signed?
- Are release commits verified?
- Are builds reproducible?
- How should users verify downloads?
- How should exchanges verify daemon binaries?

## What this page does not claim

This page does not claim:

- That release assets are signed.
- That checksum manifests exist.
- That builds are reproducible.
- That GitHub release metadata alone is sufficient for exchange-grade verification.

Those claims need direct verification.

## Open items

- Review all release assets.
- Check for checksum files.
- Check for detached signatures.
- Check for signed tags.
- Check for reproducible build documentation.
- Ask maintainers for preferred release verification process if public sources are incomplete.
