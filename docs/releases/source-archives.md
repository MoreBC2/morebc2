## Boundaries

GitHub-generated source archives are not:

- uploaded release binaries,
- checksum manifests,
- detached signatures,
- signed source artifacts,
- proof that release binaries match source.

MoreBC2 downloaded and independently hashed both archives on 2026-08-27:
