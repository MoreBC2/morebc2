## Authentication boundary

These GitHub API digest values are useful hosting-provider metadata, but they are not equivalent to:

- a maintainer-signed checksum manifest;
- a detached signature over release assets;
- a trusted BitcoinII release-signing key;
- independent reproducible-build proof;
- an independent MoreBC2 hash-and-authentication record.

The earlier `v29.1.0` MoreBC2 artifact audit remains historical evidence for that release only and must not be reused as authentication evidence for `v31.1.0`.
