The encyclopedia section is for short, cross-linked explainers of concepts used throughout MoreBC2.

Encyclopedia pages should stay neutral. BitcoinII-specific claims should appear only when they are source-backed or clearly marked as needing review.

## Page format

Each encyclopedia page should include:

- Summary
- Concept explanation
- Why it matters
- BitcoinII-specific notes, if verified
- Related pages
- Sources
- Verification block

## Rules

- Keep general concepts neutral.
- Add BitcoinII-specific details only when verified.
- Link to documentation pages when a concept is used in BitcoinII.
- Mark uncertain or unverified project-specific claims clearly.
- Do not turn encyclopedia pages into implementation source reviews; link to Source Atlas instead.
- Move command examples to wallet/node/RPC docs rather than encyclopedia pages.
