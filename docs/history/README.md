# History

This section is for preserving BitcoinII (BC2) ecosystem history.

History pages should be dated and sourced whenever possible. Older information may no longer describe the current network, wallet, or development state.

## Possible pages

- Timeline
- Major releases
- Exchange listings
- Wallet milestones
- Mining history
- Community milestones
- Archived resources

## Important rule

Historical information should not be treated as current documentation unless it has been re-verified.
