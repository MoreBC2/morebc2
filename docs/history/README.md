## Summary

This section is for preserving BitcoinII (BC2) ecosystem history.

History pages should record past events, milestones, resources, and context without confusing older information for current documentation.

## Current pages

Add history pages here only when they have dates, sources, and clear status labels.

## Rules

- Historical information should not be treated as current documentation unless it has been re-verified.
- Date historical claims whenever possible.
- Prefer archived sources, official release notes, repository history, and dated public statements.
- Mark broken or archived links clearly.
- Separate history from current ecosystem status.
- Move current facts into Documentation or Ecosystem only after direct current checks.
- Avoid using history pages to imply that an old service, explorer, exchange, or pool is still active.
