# MoreBC2 site development

This branch contains the first non-destructive Starlight website scaffold for MoreBC2.

## Design rule

The existing Markdown files remain the canonical documentation source. The website build does not require contributors to move or duplicate those files by hand.

`scripts/build-site-content.mjs` generates Starlight-compatible copies under `src/content/docs/` at build time. Generated files are ignored by Git.

The adapter currently:

- reads Markdown under `docs/`, excluding website-planning drafts under `docs/site/`;
- adds required Starlight title and description frontmatter from the existing first-level heading;
- removes the duplicate top-level heading from the generated copy;
- maps section `README.md` files to Starlight `index.md` routes;
- rewrites links between Markdown documentation pages to website routes;
- includes selected root project documents under `/project/` for contributor and status references;
- validates exact-case Markdown link targets and rejects duplicate generated routes;
- hides section indexes and clearly internal review-coordination pages from autogenerated navigation while keeping their routes accessible.

`scripts/protect-preview-content.mjs` performs preview-only publication protection after content generation. It excludes hidden generated pages from Starlight's Pagefind search index without modifying the canonical Markdown.

## Local requirements

- Node.js 22.12.0 or newer
- npm

## Local preview

```sh
npm install
npm run dev
```

## Validation

```sh
npm run build
npm run check
```

`npm run build` also audits the generated HTML for unresolved internal routes,
missing anchors, and local links that still end in `.md`.

The branch also includes `.github/workflows/site-check.yml` so GitHub can validate the static build without Codex usage.

## Cloudflare target

The preview is deployed at <https://morebc2.pages.dev/> with these Pages settings:

- Build command: `npm run build`
- Output directory: `dist`
- Production branch: `site/starlight-preview`

## Preview publication boundary

This Pages deployment is a review preview, not the public launch. It intentionally uses multiple indexing protections:

- `public/robots.txt` disallows crawling for all user agents;
- Starlight adds a site-wide `robots` meta directive with `noindex, nofollow, noarchive, nosnippet`;
- `public/_headers` adds the same intent at Cloudflare's HTTP-response layer using `X-Robots-Tag`;
- hidden working pages are excluded from the site's Pagefind search index.

These controls reduce accidental discovery but are not access control. Anyone who knows a direct preview URL can still request a generated page. Material that must be confidential should not be generated into the static site at all.

The site remains a static preview. Switching production to `main`, changing canonical URLs, removing preview indexing protections, or attaching a permanent domain are separate human decisions after review and merge.
