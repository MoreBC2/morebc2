# MoreBC2 Manifesto

MoreBC2 exists because useful knowledge should not disappear into chat history.

Small open-source ecosystems often run on memory. Someone remembers a link. Someone remembers a developer comment. Someone remembers how a wallet was built, which explorer worked, or why a decision was made. That works until people leave, links break, conversations move on, or new contributors arrive and have to ask the same questions again.

MoreBC2 is an attempt to preserve that knowledge before it gets lost.

## We document reality

MoreBC2 should describe what BitcoinII is, how it works, and where information can be verified.

It should not invent authority. It should not turn rumors into facts. It should not confuse discussion with implementation.

## We separate facts from ideas

Facts, research, discussion, and history all matter.

But they must be clearly separated.

A shipped feature belongs in Documentation.

A technical comparison belongs in Research.

A community proposal belongs in Discussion.

A past event belongs in History.

This separation keeps readers from mistaking possibility for reality.

## We respect primary sources

Source code, release notes, official project resources, and live network behavior matter more than memory or opinion.

MoreBC2 is not the source of truth. It is a map to the source of truth.

## We admit uncertainty

A good documentation project does not need to pretend.

When something is unknown, say it is unknown.

When something needs review, mark it Needs Review.

When something is based only on community discussion, label it as discussion.

## We build for future contributors

MoreBC2 should be understandable to someone who arrives years later.

The structure, templates, style rules, source registry, evidence scale, and verification queue all exist so future contributors can continue the work without guessing the intent.

## We avoid hype

MoreBC2 is not for predictions or unsupported promotion.

It exists to make the BitcoinII ecosystem easier to understand, verify, and build around.

## The goal

The goal is simple:

Preserve the knowledge. Strengthen the ecosystem.
